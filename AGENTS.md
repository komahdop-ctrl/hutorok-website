# AGENTS.md — инструкции для Codex Cloud

## Проект
«Пасека Хуторок» — отдельный сайт семейной пасеки. Уточняй задачу по README.md. Сейчас сайт представляет собой базовую адаптивную заготовку под будущий дизайн.

## Сборка
- React + TypeScript + Vite, без навязывания новых UI-фреймворков без необходимости.
- Ориентируйся на GitHub Actions: Node.js 22, `npm install`, `npm run build`.
- Для разработки: `npm run dev -- --host 0.0.0.0`. Проверяй TypeScript и мобильную вёрстку.
- Сохраняй структуру `src/` и `public/`, не допускай случайного добавления секретов в код или историю коммитов.

## Работа с GitHub
- Создавай отдельную ветку и Pull Request. Не меняй `main` и не выполняй merge без прямого разрешения владельца.
- Push в `main` запускает GitHub Pages. Не публикуй сайт без проверки.
- Не меняй настройки DNS, хостинга, Actions, доступов и токенов без отдельного согласования.
- Не смешивай изменения этого сайта с другим репозиторием «ПЧЕЛОВОД 63».
- Сначала предлагай минимальные изменения и объясняй, какие именно страницы и функции они затрагивают.

## Контент и отчёты
- Текст интерфейса — на русском.
- Не размещай фотографии и истории людей без разрешения; не выдумывай подтверждения или свойства продукции.
- По завершении дай краткий отчёт по-русски: что изменено, что проверено, ошибки, ссылка на PR, дальнейшие решения владельца.
