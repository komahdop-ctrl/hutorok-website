# Тестовая публикация «Хуторка» на Beget

Workflow `.github/workflows/beget-test.yml` собирает main с Node 22 и публикует только dist в `/home/v/vendingi/vendingi.beget.tech/public_html/hutorok-website/`.

Ожидаемый адрес после успешного запуска: https://vendingi.beget.tech/hutorok-website/ . Наличие этой инструкции не подтверждает публикацию.

Нужен repository secret `BEGET_SSH_KEY`: приватный ключ, публичная часть которого уже установлена на аккаунте vendingi. Ключ без пароля; зашифрованный ключ остановит workflow. Владелец вносит значение непосредственно в GitHub Settings → Secrets and variables → Actions. Не добавлять ключ в репозиторий, чат, issue или артефакты. Через доступный GitHub connector установить secret нельзя.

Workflow запускается при push в main или вручную после появления в default branch. До слияния работает существующая проверка PR; она не проверяет SSH. Отсутствующий secret, изменившийся отпечаток сервера и ошибка HTTPS завершают публикацию ошибкой.

Отпечаток ED25519 был сверен владельцем через терминал панели Beget: SHA256:4+NodSyDnT38XilJxBKCva9nOl+04LnsAMKZpr0mh48. При изменении требуется новая независимая проверка. Проверка сертификата HTTPS не отключается.

Перед повторным обновлением архив текущей версии сохраняется в `~/hutorok-backups/` вне webroot. Удаление старых копий не автоматизировано: контролировать квоту. Это локальные копии для отката, не независимый аварийный бэкап. Первый запуск откажется перезаписать незнакомую существующую папку. Соседние сайты не удаляются. rsync сохраняет старые assets; delay-updates не обеспечивает атомарности всей версии. При ошибке HTTPS файлы уже могут быть загружены: результат требует проверки, автоматического отката пока нет.

В конце проверяются маркер SHA, index и privacy.html по HTTPS. Это не браузерный тест, аудит права или доказательство готовности всех форм. Существующие noindex и отключённые формы сохранены. Внешние фотографии Unsplash пока загружаются с внешнего сервиса; перенос HTML не локализует их обработку.
