# Рабочие результаты аудита «Пасека Хуторок» (24.10.2026)

Проверен репозиторий komahdop-ctrl/hutorok-website (ветка main на дату начала аудита). Статический React/Vite на GitHub Pages. README указывает https://komahdop-ctrl.github.io/hutorok-website/; прямая проверка публичного URL инструментом веб-поиска не удалась, поэтому доступность релиза требует отдельной проверки.

## Исходное состояние
- Каталог с 9 видами меда, ориентировочные цены, годы урожая.
- В каждой фасовке активная схема sms: для отправки сообщения с названием меда и ценой; есть общая SMS-кнопка.
- В коде нет форм, серверного API заказов, корзины, платежной интеграции, аналитических скриптов и собственной БД.
- Два телефона в интерфейсе, адрес пасеки без точного домашнего адреса.
- Удаленных хранилищ в дереве репозитория нет; история git, GitHub Actions artifacts, access logs провайдера, внешние резервные копии не доказаны отсутствующими.
- Изображения (без фото членов семьи) приходят с Unsplash; Google Fonts был внешней зависимостью.
- Собственные фото пасеки по README в репозиторий ещё не добавлены.

## Безопасные изменения в audit-legal-2026-10-24
- Удалены SMS-ссылки оформления заказа (в карточках и контактах).
- Добавлен явный статус тестовой информационной версии и справочных цен.
- Добавлена локальная для сайта страница `privacy.html` с описанием фактического состояния и открытых ограничений.
- Добавлена заметная ссылка на политику в футере.
- Удалена внешняя загрузка Google Fonts; используются системные шрифты и Georgia.
- Тестовая версия обозначена как noindex и закрыта в robots.txt; вернуть индексацию только после запуска.
- Адаптирован браузерный тест под запрет SMS-ссылок.
- Создан шаблон будущего согласия, но не подключена никакая форма.

## Не решено и НЕ должно называться завершенным
1. Правовой статус продавца и номер ОГРНИП (если ИП) либо документы ЛПХ / иной режим.
2. Адрес оператора для писем, статус и договоры с обработчиками.
3. GitHub Pages и Unsplash: внешняя обработка технических данных, серверные логи, место хранения, сроки, трансграничная оценка. Перед запуском автоматизированных форм нужен соответствующий РФ контур.
4. Подтверждение согласия на размещение идентифицируемых фото третьих лиц при добавлении оригиналов в будущем.
5. Проверка маркировки мёда, требований безопасности продуктов, документов на партию и режима законной продажи.
6. Ручная проверка реального URL, TLS, privacy.html, карточек и мобильного вида после публикации.
7. Фактические истории git/Actions/резервных копий и хранилищ вне репозитория (доступ на уровне провайдера необходим).

## Нормативные ориентиры
- Федеральный закон № 152-ФЗ, статьи 6, 9, 12, 18, 18.1, 19, 22.
- Закон РФ № 2300-I, статьи 8, 10 и 26.1.
- Применимые Правила продажи товаров по договору розничной купли-продажи, ТР ТС 021/2011 и 022/2011, и специальные нормы реализации мёда.
- Проверка обязательного уведомления в РКН — до запуска соответствующей обработки, исключения статьи 22 узкие.

Внесение программного изменения и создание политики само по себе не является подтверждением общей юридической готовности ресурса.
