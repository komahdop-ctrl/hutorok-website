## Коммерческие и юридические ограничения
- Не подключать формы, корзину, онлайн-заказы, оплату, CRM/API, SMS или автоматические мессенджерные заявки.
- Не собирать и не передавать ПДн. Выбор товара и желаемой фасовки хранится только в состоянии открытой страницы; контакт — только добровольный tel: переход.
- Сохранить noindex,nofollow и Disallow: / до отдельного решения о домене и публичном SEO-релизе.
- Не добавлять фальшивые отзывы, сертификаты, лечебные обещания, неподтверждённые цены и остатки.
- Не покупать подписки и не расходовать дополнительные кредитные SEO/API-сервисы.
- Не управлять общей браузерной сессией Telegram, принадлежащей ЦУП Вендинг-Сервиса.

## Публикация
- GitHub Pages — текущая тестовая публикация, закрытая от индексации.
- PR #5 — Beget deployment. Для запуска требуется repository secret BEGET_SSH_KEY, который владелец добавляет непосредственно в GitHub Settings → Secrets and variables → Actions. Никогда не отправлять секрет в чат/issue/репозиторий.
- Beget не считать опубликованным до успешного workflow и проверки опубликованного SHA/HTTPS.
- Домен, поисковые кабинеты, Figma и SEO-подписки не блокируют независимую разработку.

## Приёмка
1. npm ci и npm run build проходят.
2. Основной контент находится в dist/index.html до выполнения JS.
3. Browser QA проходит на desktop и мобильных ширинах 320/375/390/768.
4. Все изображения загружаются с домена сайта, имеют alt; нет Unsplash, внешних шрифтов и сторонних запросов.
5. Нет форм, корзины, заказов, оплаты, SMS, аналитики или передачи ПДн.
6. Выбор товара/фасовки понятен, но не обещает наличие/цену; связь осуществляется добровольным звонком.
7. Тестовая индексация остаётся закрытой.
8. PR и CI доказательства сохранены; Beget/production статус обозначается только по факту.
9. После принятия кандидата отдельно подтверждаются цены, фасовки, продавец, документы, условия получения и домен; только затем готовится публичный коммерческий релиз.
