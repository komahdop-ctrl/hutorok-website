# Пасека «Хуторок»

Сайт семейной пасеки (React, TypeScript, Vite). Это продолжение существующего проекта, без переноса в новый репозиторий.

## Публикация

- Адрес публикации, заявленный в конфигурации: https://komahdop-ctrl.github.io/hutorok-website/ (фактическую доступность проверять после деплоя).
- GitHub Pages из `main` через `.github/workflows/deploy.yml`.
- Сборка: `npm install && npm run build`.
- Проверка перед слиянием: `.github/workflows/verify-pr.yml`.

## Каталог и обновление цен

Сорта, годы урожая, фасовки и цены задаются в массиве `honey` файла `src/App.tsx`.

**Важно:** не переносите цены одного урожая на другой и не вычисляйте стоимость 1 или 3 л делением цены 10-литрового ведра. Добавляйте только проверенные фасовки. Если урожай товара неизвестен, оставьте `уточняется`.

**Тестовая версия с 24.10.2026:** отправка SMS-заказов через сайт отключена. В каталоге видны справочные фасовки и цены без активных кнопок заказа. Оба телефона доступны только для самостоятельного информационного обращения. Онлайн-оплата и формы не применяются.

## Изображения

Пока используются тематические фотографии с Unsplash (авторы и источник указаны на сайте) и иллюстративные изображения банок средствами CSS. Это **не фотографии нашей пасеки** и **не точное изображение реализуемой фасовки**.

Реальные фотографии пасеки нужно добавить из архива с согласованными подписями. См. реестр фото от 16.10.2026 (оригиналы хранятся отдельно; в репозитории их пока нет). Не публикуйте портреты с заменой лица или сгенерированные производственные объекты под видом реальных.

## Дизайн и доступность

Светлая солнечно-луговая палитра, мобильное меню, responsive-карточки, доступная навигация, анимация с учётом `prefers-reduced-motion`.

## Юридическая тестовая версия (24 октября 2026)

- Сайт не принимает заявки и оплату; карточки товаров информационные.
- Политика обработки персональных данных: `public/privacy.html` (в публикации `/hutorok-website/privacy.html`). Текст описывает фактические ограничения и должен быть дополнен по мере уточнения статуса оператора и хостинга.
- Шаблон согласия на будущие формы: `docs/consent-template.md`, **не действует** и никуда не подключён.
- Технический и юридический аудит с ограничениями проверки: `docs/legal-audit-2026-10-24.md`.
- В тестовой версии установлено `noindex` и закрытие через robots.txt. До запуска полноценной публичной продажи — уточнить продавца, безопасность хранения и документы на мёд.
- Текущая публикация использует GitHub Pages и изображения Unsplash; размещение технических логов и возможная обработка за рубежом требуют дополнительного обследования.
