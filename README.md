# Пасека «Хуторок»

Современный сайт семейной пасеки. Проект подготовлен как чистая основа для последующего переноса дизайна из Figma.

## Стек

- React
- TypeScript
- Vite
- CSS без UI-фреймворка

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
npm run preview
```

## Структура

- `src/` — компоненты и стили приложения
- `public/` — статические файлы
- `index.html` — входная HTML-страница

Пока проект содержит лёгкую адаптивную страницу-заглушку в тёплом eco/фермерском стиле. Она намеренно не перегружена логикой, чтобы стать основой для точного переноса макета из Figma.
