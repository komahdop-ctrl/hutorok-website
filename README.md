# Пасека «Хуторок»

Сайт семейной пасеки в селе Русская Селитьба, Красноярский район, Самарская область. Стек: React 19, TypeScript, Vite 7.

## Состояние проекта

Рабочая ветка кандидата EUCP-HUTOR-001: feature/eucp-hutor-001-commercial-candidate. Управление проектом ведётся в существующей ветке ChatGPT «SEO-ветка Пасека Хуторок»; 0-0 — независимый контроль. Основной реестр исполнения — GitHub issue EUCP-HUTOR-001.

## Публикация и сборка

- Текущая тестовая публикация: https://komahdop-ctrl.github.io/hutorok-website/
- GitHub Pages из main через workflow deploy.
- Установка зависимостей: npm ci.
- Сборка: npm run build.
- Build выполняет TypeScript, Vite и предварительный рендер главной страницы в dist/index.html.
- Preview: npm run preview.
- CI: verify-pr и browser-qa.

## Каталог и коммерческие ограничения

Каталог описывает медосборы и продукты, которые ранее обсуждались для пасеки. Цены и остатки намеренно не опубликованы: перед продажей их необходимо подтвердить. В карточках можно выбрать желаемую фасовку (1, 3, 10 л или подобрать; для сотового мёда — полурамка), но выбор не подтверждает наличие тары или товара.

Путь пользователя: выбрать продукт и пожелание по фасовке → перейти к контактам → самостоятельно позвонить. Выбор хранится только в памяти открытой страницы, не передаётся на сервер и не сохраняется. Сайт не принимает онлайн-заказы, не содержит форм, корзины, оплаты, SMS/мессенджерных автозаказов и аналитических пикселей.

До подтверждения продавца, условий реализации, доставки, документов, оператора ПДн и хостинга не включать сбор заявок, оплату или индексацию.

## SEO, доступность и безопасность тестовой версии

- Основной контент предварительно рендерится в HTML; клиентская часть гидратирует готовую разметку.
- Есть title, description, canonical, Open Graph, JSON-LD WebSite/Organization, локальная OG-картинка и preload главного фото.
- Тестовая версия остаётся закрытой от индексации: meta robots noindex,nofollow и Disallow: / в robots.txt. Не снимать до утверждения домена и публичного запуска.
- Структура использует один H1, семантические секции, подписи изображений, skip-link, видимый focus, мобильную навигацию и prefers-reduced-motion.
- Внешние шрифты, фотохостинги, аналитика и рекламные пиксели не подключены.

## Дизайн

Направление: светлый премиальный natural/eco, кремовые поверхности, мягкие медовые акценты и оливковая зелень, без тяжёлого фонового изображения и чрезмерного декора. Figma-файл содержит ранний каркас с заглушками; он не является основанием для неподтверждённых отзывов или обещаний доставки.

## Выпуск на Beget

PR #5 остаётся отдельным открытым PR. Для его workflow нужен GitHub repository secret BEGET_SSH_KEY, добавляемый владельцем только в GitHub Settings → Secrets and variables → Actions. Секрет нельзя передавать в чат или репозиторий. Наличие секрета и фактическая публикация подтверждаются только успешным workflow и проверкой опубликованного SHA/HTTPS. До этого Beget не считать работающим.

## Проверки перед публичным запуском

1. Подтвердить основной домен и canonical.
2. Сверить актуальные цены, фасовки и остатки по каждому продукту.
3. Подтвердить условия получения/доставки и продавца.
4. Проверить документы и обязательную маркировку продукции.
5. Установить фактического оператора ПДн, хостинг, базы и порядок хранения; только после этого проектировать форму/заказ.
6. Подключить Яндекс Вебмастер и Google Search Console, отправить sitemap.
7. Измерить Lighthouse/Core Web Vitals на конечном домене.
8. После отдельного разрешения снять noindex/robots запрет.
